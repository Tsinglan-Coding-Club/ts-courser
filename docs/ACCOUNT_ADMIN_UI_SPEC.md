# 管理员学生账号创建

状态：2026-09-08。已实现单个学生创建、按姓名表格批量创建、创建结果展示与打印，以及教师审核。属于 [账号系统升级方案](ACCOUNT_SYSTEM_UPGRADE_PLAN.md)。所有示例均为虚构内容。

## 单个创建

入口：账号管理 → Create local student。

管理员填写用户名、学生姓名和初始密码；联系邮箱可选。用户名由管理员指定并经过格式和重名校验，密码不自动生成。保留此入口用于需要自定义用户名的账号。

## 批量创建

入口：账号管理 → Create students in bulk。实际路由为 `/accounts/manage/local-students/bulk/`。

1. 在表格中逐行填写学生姓名，可添加、删除行，也可将表格软件中的一列姓名粘贴到任意姓名格。多行粘贴会在当前行后插入新行，保留后面已填的学生。
2. 点击 Preview usernames。服务器生成并展示每个学生的用户名，此时不创建账号，也不需要密码。
3. 核对“学生姓名 → 用户名”表格，填写一个 Shared initial password，点击 Create student accounts。该密码用于本批所有学生。
4. 创建成功后显示学生人数、姓名与用户名清单、统一初始密码和有效期；可打印清单或返回创建下一批。

每批至少一人，最多 200 行，空白行忽略。姓名最多 100 个字符，支持英文姓名或拼音。无需填写邮箱、学号或班级。

### 用户名规则

| 输入姓名 | 生成的用户名示例 |
| --- | --- |
| Abby Ai | abbyai |
| Bob Li | bobli |
| Anne-Marie O’Neil | annemarieoneil |
| José Muñoz | josemunoz |
| 再次出现 Abby Ai | abbyai2（该后缀可用时） |

服务器转为小写，使用 Unicode 兼容分解简化重音及全角字符，随后仅保留 ASCII 字母和数字。基础用户名最多 100 个字符，为数字后缀留出空间。无法得到任何字母或数字时提示填写英文名或拼音；不自动猜测中文姓名的拼音。显示姓名保留大小写及标点，连续空白合并。

与已有账号或本批前面行重名时，从 `2` 起依次尝试数字后缀，跳过已使用的用户名。已有账号的检查不区分大小写，包含停用账号及所有角色。同名学生可拥有不同账号；不会按姓名合并学习档案。

### 预览与提交

预览签名绑定当前管理员、姓名及分配的用户名，有效期十分钟，不包含密码。修改姓名或增删行后必须重新预览；服务器也会核对提交的名单，不能依靠页面按钮限制。

提交时重新检查预览中的用户名是否可用，以事务创建整批账号。若预览后发生重名或创建期间触发数据库唯一约束，则整批回滚，提示重新预览。不会在提交时静默更改已确认的用户名。

重复提交同一已成功的预览会因用户名占用而拒绝，不重复建号、不重置已创建学生的密码。当前没有持久批次记录或结果恢复入口。

## 密码与首次登录

初始密码由管理员指定，允许便于课堂发放的简单密码；批量创建允许整批使用同一密码。每个学生分别通过 Django 密码哈希保存凭据。初始有效期继续使用 `LOCAL_INITIAL_PASSWORD_TTL_DAYS`，默认七天。

初始密码只在本次创建结果页展示，页面禁止缓存，不保存到预览、URL、长期会话或数据库明文字段。关闭后无法从平台查询原密码。

学生首次登录保留管理员指定或按姓名生成的用户名，必须设置不同的新密码并通过现有强度和两次输入校验，成功后才建立正常登录会话。既有未完成首次登录的学生也保留原用户名。本地管理员账号的首次凭据设置规则不变。

## 权限和验收

只有平台管理员可以预览或创建学生，`is_staff` 本身不授予此权限。所有提交要求 CSRF 校验。账号角色始终为学生，不接受客户端提升角色或后台权限。

回归覆盖姓名规范化、同批与已有账号重名、无效名单、批次数量限制、预览过期及篡改、跨管理员预览、统一密码哈希、整批回滚、重复提交、权限和首次改密。页面验证使用隔离数据库及虚构账号。
