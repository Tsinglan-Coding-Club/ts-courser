# 管理员发号界面与接口规格

状态：2026-09-07 已实现单个学生账号创建、一次性初始密码展示和教师审核；本文件其余批量录入、预览、打印卡与导出流程仍是后续设计。属于 [账号系统升级方案](ACCOUNT_SYSTEM_UPGRADE_PLAN.md)。所有示例均为虚构内容；真实学生资料由管理员在产品中输入，不需要提供给开发者。

## 页面结构

入口：账号管理 → 小学生账号 → 批量创建。

```text
小学生账号                                      [单个创建] [批量创建]

输入方式  [表格填写] [粘贴文本] [上传文件]

统一班级  [选择或新建班级]        批次备注  [例如：三年级开学发号]

表格填写：
姓名或标签       班级             学号（可选）   学校账号（可选）
示例学生甲       统一班级         __________    __________________
示例学生乙       统一班级         __________    __________________
[增加一行] [按人数生成待分配行：30]

登录名  [自动生成]   初始密码  [系统逐人生成]

                               [取消] [检查并预览]
```

页面默认自动生成登录名，可展开“高级选项”按行指定。初始密码不提供自定义输入，角色固定为学生，也不出现 `is_staff`、`is_superuser` 等底层字段。

“按人数生成”产生“待分配 01”等临时标签及独立账号，管理员可在预览中填姓名或创建后分配。它不会生成或猜测任何人的 Microsoft 身份。

## 三种输入共用同一套创建流程

| 输入方式 | 交互规则 |
| --- | --- |
| 表格填写 | 添加、删除行；选择整批默认班级或逐行覆盖；即时提示空行和格式错误 |
| 粘贴文本 | 接受 CSV 逗号分隔，或从 Excel/其他表格复制的 TSV；支持有表头/无表头选择，预览列映射，不用简单字符串分割处理引号 |
| 上传文件 | 首版支持 UTF-8 CSV（含 BOM）和 TSV；下载模板，提示 Excel 可另存 CSV；不默认支持 `.xls`、宏文件或 `.xlsx`，后者可单独追加 |

无表头粘贴时先选择列顺序，默认“姓名、班级、学号、学校账号、登录名”；一列姓名也可配合默认班级使用。分隔符自动识别后显示识别结果并允许更正，避免误读。文件和文本导入使用同一 CSV 解析规则，正确处理引号内的逗号与换行。

| 字段 | 必填性 | 规则 |
| --- | --- | --- |
| 姓名或标签 | 需要一个显示标签 | 手填姓名或由“按人数生成”产生标签；同名可以存在 |
| 班级 | 可选 | 使用逐行值或统一班级；未分班显示“待分班” |
| 学号 | 可选 | 填写时校验唯一性；为空时仍自动生成独立内部编号，不伪造学校学号 |
| 学校账号 | 可选 | 只作为未来关联提示；输入它不创建 Microsoft 账号、不证明该学生拥有此身份 |
| 登录名 | 默认自动生成 | 简短、唯一、稳定；管理员指定时仍经过服务器验证；不因升班、改名而变化 |
| 初始密码 | 不允许输入 | 提交时由服务端逐人生成；预览中不产生真实密码 |

文件模板：

```csv
姓名,班级,学号,学校账号,登录名
示例学生甲,三年级A班,,,
示例学生乙,三年级A班,,,
```

## 预览、确认与结果

```text
检查结果：共 30 行 · 28 行可创建 · 2 行需要修改

行号  姓名/标签    班级       登录名      状态
1     示例学生甲   三年级A班  s482731     可创建
2     示例学生乙   三年级A班  s751294     同班同名，需核对
3     示例学生丙   三年级A班  s482731     登录名重复，请修改

[返回修改] [导出错误报告]                  [确认创建]（有错误时禁用）
```

预览规则：

- 重复学号、指定登录名冲突、未知班级等是可定位到行和字段的错误。同名只提示核对，不能自动覆盖、合并或删除账号。
- 没有学号或其他稳定外部标识时，不声称能识别所有跨批次重复人员；显示同名/同班候选供管理员核查。
- 用户可返回编辑；任何输入改动都会使旧预览失效。提交时重新校验所有服务器规则，不信任客户端的“已通过”标志。
- 首版建议一批最多 200 行，文件大小和实际上限作为配置；更大批次先分批，测量密码哈希耗时后再决定后台队列。
- 预览里自动生成的登录名是拟用值；提交时若产生并发冲突，返回明确冲突并要求重新预览，不静默覆盖已有账号。
- 有错误时整批不提交。确认后用事务、数据库唯一约束和幂等键保证重复点击只创建一次。

创建完成页显示批次编号、账号数量、每人的登录名及当次初始密码，提供“打印账号卡”“导出本次 CSV”“返回账号列表”。初始密码只在当前结果页交付；页面关闭后不能查询原密码，后续补发必须重置。

结果响应丢失或刷新后，历史批次仍能查询创建是否成功、用户列表和发放状态，但不能重放明文密码。管理员可仅对需要补发的选定账号重置；重复提交原请求不重新生成密码。

打印卡包含网站地址、学生标签/姓名、班级、登录名、初始密码及“首次登录请修改密码”。明文凭据不写日志或长期数据库字段；结果响应禁止缓存。输出 CSV 对用户输入做单元格转义和公式防护。

## 后端接口契约（拟议）

| 路由 | 方法 | 作用 |
| --- | --- | --- |
| `/accounts/manage/students/` | GET | 学生账号列表、班级/状态/批次筛选 |
| `/accounts/manage/students/new/` | GET | 单个或批量创建表单 |
| `/accounts/manage/students/template.csv` | GET | 下载虚构内容的导入模板 |
| `/accounts/manage/batches/preview/` | POST | 接收表格行、粘贴文本或文件；解析、验证，返回预览 ID、拟建账号及逐行错误 |
| `/accounts/manage/batches/commit/` | POST | 消费属于当前管理员的有效预览，重新检查，事务创建账号和密码；返回当次交付结果 |
| `/accounts/manage/batches/<id>/` | GET | 查询历史批次状态和关联账号，不返回密码 |
| `/accounts/manage/users/<id>/reset-password/` | POST | 确认后重置选定本地账号，撤销原凭据与会话，重新要求首次改密 |
| `/accounts/manage/users/<id>/status/` | POST | 启用或停用；记录原因与操作者 |

所有接口都要求平台管理员权限；POST 使用 CSRF 防护。教师和学生请求这些接口返回拒绝，不能依赖前端隐藏入口。输入中出现自选 `role`、权限标记或密码字段时拒绝处理。

`preview` 输入有且只有一种来源：规范化 `rows`、带分隔/表头选项的 `text` 或上传的 `file`，外加默认班级与备注。错误沿用项目 JSON 风格：`success: false`，附带行号、字段和可读原因。HTTP 400 表示输入错误，403 表示无权限，409 表示并发或重复身份冲突，429 表示限速。

`commit` 仅提交预览 ID 和幂等键；服务器保存短时草稿并绑定管理员、内容摘要和过期时间。草稿变化、过期、操作者不符均拒绝。草稿保存的是管理员输入和拟用登录名，不包含密码。日志记录批次统计和动作，不记录原始文件或凭据。

## 相关日常页面

- 账号列表：显示待分配、待首次改密、正常、初始密码过期、停用等状态；按班级或批次查找。
- 账号详情：编辑显示名/班级、查看学校身份是否已关联、停用、重置；管理员看不到学生设置后的密码。
- 教师审核：显示已通过学校 Microsoft 认证的待确认用户和命名提示；批准后才授予教师权限。无毕业年份不是自动批准条件。
- 学生账号安全：显示本地和 Microsoft 登录是否可用；关联学校身份时需要实际 Microsoft 认证及本地账号验证，不按相同邮箱直接绑定。

## 页面验收

1. 管理员不借助开发者即可手填、粘贴或上传完成发号；无学号、无邮箱也可创建。
2. 空行、引号内逗号、中文表头、BOM、粘贴表格、同名、重复编号和未知列均有明确结果。
3. 重复点击、网络重试和两个管理员并发创建不会覆盖账号或静默重置密码。
4. 教师和学生不能调用创建、导出、重置或停用接口；导入字段不能提升角色。
5. 学生用初始密码登录后必须改密；重置后旧密码和旧会话失效。
6. 全部开发和自动化验证使用虚构数据，不要求用户提供真实小学生名单。
